# Machine Learning Algorithms on Human Control(precision) Data from Archery 

## Objective

To understand how ML algorithms behave when data comes from environmental and human performance variables, focusing not only on prediction accuracy but on how machine learning models predict arrow impact under realistic variations.

## Problem Statement

In real world sports environments, performance depends on many interacting factors. This project aims to simulate these conditions and evaluate whether classical machine learning models can learn meaningful relationships between shooting conditions and arrow outcomes.

## Motivation

To study machine learning in a messy human system where variability and uncertainty are unavoidable, dealing with hidden states, uncertainty, failure analysis, and understanding where and why models fail when assumptions break.

## Research Question

How does machine learning behave when learning from a human performance system where variability and uncertainty are unavoidable?

What hidden structure generates the observations?

How do we infer hidden reality from noisy observations and use that understanding to make better predictions?

## Objectives

* Build a synthetic human-performance dataset with controlled simulation grounded in real variability patterns.
* Study observable data and measurements, inference systems, hidden state estimation, and prediction.
* Analyze prediction confidence, uncertainty, and failure behavior.
* Understand what happens when ML model assumptions break.

## Approach

Build a synthetic dataset that simulates real-world archery conditions using controlled variability patterns.
Use observable data and measurements to train classical machine learning models and evaluate how they learn, predict, and behave under different conditions.
Analyze model performance by studying prediction behaviour, failure cases, and the hidden structures behind observed data.
